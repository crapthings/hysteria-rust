# v0.1.0-rc.7 — Pre-release

This release expands standalone client/server tooling, adds client routing and
profiles, and improves connection recovery and UDP handling. Each executable
contains both the client and server.

## Highlights

- Client profiles with private storage and sharing-link import; guided setup,
  offline validation and phased connection diagnosis with JSON reports.
- Versioned client lifecycle events on stdout (`client --events json`) for GUI
  and script integration. Persistent control IPC and live configuration reload
  are not implemented.
- Client routing v1: domain/IP and protocol/port rules, local rule sets,
  proxy/direct/reject decisions, explain/trace and conservative lint.
- Protected Linux routed TUN with persistent, bounded Fake-IP DNS and opt-in
  system-resolver diagnosis. Other-platform routed TUN is not implemented.
- Demand-driven connection recovery with coalesced attempts and failure cooldown.
  Closed TCP streams cannot resume; UDP remains best-effort.
- Read-only server status/statistics, named Linux systemd services, server sharing
  links, ECH key generation/rotation tooling and improved configuration errors.
- Fix Brutal minimum congestion-window stalls; reduce UDP payload copying and
  improve routing-set indexing and Fake-IP persistence under concurrent load.
- Refresh networking/TLS dependencies and require Rust 1.91 for source builds
  (pinned toolchain: 1.91.1).

See [CHANGELOG](../../CHANGELOG.md) for the full changes.

## Validation and boundaries

Ordinary Linux client routing and isolated TUN/DNS/application acceptance have
passed the recorded jp1 checks. Whole-host DNS integration, network handover,
sleep/wake and long-running use remain platform acceptance work. Starting TUN
alone does not guarantee system DNS capture.

Release publication is gated on workspace tests and lint, vendored HTTP/3 and
QUIC tests, pinned Go/Rust interoperability, and all seven platform packages.
The Go interoperability reference is app/v2.13.0 at
`ca8fbd874fd6ca82413948de6dc5924405e103e1`.

## Downloads

Prebuilt binaries cover Linux x64, ARM64 and ARMv7; macOS x64 and ARM64;
Windows x64 and ARM64, with adjacent SHA-256 checksums. Linux binaries require
glibc. This is a prerelease; retain your previous binary and configuration for
rollback.
