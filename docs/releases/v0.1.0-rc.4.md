# v0.1.0-rc.4 — Pre-release

This release fixes server dual-stack listening and updates certificate trust
dependencies. Each executable contains both the client and server.

## Fixes

- Server `listen: ":443"` now prefers one dual-stack UDP socket and falls back
  to IPv4 when IPv6 is unavailable. `listen: "[::]:443"` explicitly enables
  dual-stack; `listen: "0.0.0.0:443"` remains IPv4 only. The same socket setup
  covers ordinary QUIC, Salamander and Gecko.
- Update `rustls-webpki` to 0.103.16 and `webpki-roots` to 1.0.10 to address
  RUSTSEC-2026-0382 and RUSTSEC-2026-0381 certificate trust vulnerabilities,
  including the required AWS-LC dependency update.
- Correct the update-check environment variable in CI/release interoperability
  tests and make the listener conflict test respect Windows binding behavior.

## CI behavior

Changes limited to `README.md` no longer trigger automatic push or pull-request
CI. Changes involving code still run CI. Manual CI runs and version tags retain
their existing build and validation behavior.

## Downloads and validation

Prebuilt downloads cover Linux x64, ARM64 and ARMv7; macOS x64 and ARM64;
Windows x64 and ARM64. Every binary has an adjacent SHA-256 checksum. Linux
binaries require glibc.

The preceding main CI passed all ten jobs, including all seven platform
packages, Linux workspace and vendored protocol tests, Go interoperability,
and dependency audit. Local Go-client tests against a deployed Linux x64
server verified TLS plus TCP/UDP round trips over IPv4 and IPv6. Surge HTTP
and UDP checks passed. Release publication is gated on tag verification and
all seven platform packages.

The pinned Go interoperability baseline remains
`62d1016707af21b91e5fb6070311d9f016ff2754` with Go 1.26.5. The experimental
Chrome-shaped Rust client profile remains opt-in and does not enable ALPS.
